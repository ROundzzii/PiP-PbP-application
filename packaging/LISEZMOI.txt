PiP-PbP — voir l'écran d'un autre PC dans une fenêtre flottante
================================================================

Rien à installer : copiez ce dossier sur chacun des deux PC (clé USB, partage réseau…).
Les deux PC doivent être sur le même réseau local (même box / même switch).
Pas de compte, pas de code à partager comme AnyDesk : les PC se trouvent tout seuls.

1) Sur le PC dont vous voulez VOIR l'écran (la source) :
     double-cliquez sur  1-partager-cet-ecran.bat
   La première fois, Windows demande l'autorisation du pare-feu :
   cochez « Réseaux privés » ET « Réseaux publics », puis Autoriser.

2) Sur le PC qui AFFICHE la fenêtre (le viewer) :
     double-cliquez sur  2-afficher-l-autre-ecran.bat
   La fenêtre trouve la source automatiquement (quelques secondes).
   Si elle ne la trouve pas, ouvrez une invite de commandes ici et tapez :
     pip-pbp view 192.168.1.XX     (l'IP affichée par la source)

Dans la fenêtre :
  - souris dessus         -> transparente, les clics passent à travers
  - Alt maintenu          -> redevient normale (pour la déplacer / redimensionner)
  - molette               -> agrandir / réduire
  - double-clic ou F      -> plein écran
  - 1 / 2 / 3             -> coin (PiP) / moitié gauche / moitié droite (PbP)
  - flèches haut / bas    -> opacité au survol
  - Ctrl+Q                -> quitter

Réglages : modifiez pip-pbp.toml (opacité, fps, débit, écran capturé…).
Plusieurs écrans sur la source : « pip-pbp monitors » les liste, puis
mettez monitor = N dans pip-pbp.toml (section [send]).
