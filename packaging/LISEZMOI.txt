PiP-PbP — voir l'écran d'un autre PC dans une fenêtre flottante
================================================================

Rien à installer : copiez pip-pbp.exe sur chacun des deux PC (clé USB, partage réseau…)
et double-cliquez dessus pour ouvrir l'interface.
Les deux PC doivent être sur le même réseau local (même box / même switch).
Pas de compte, pas de code à partager comme AnyDesk : les PC se trouvent tout seuls.

1) Sur le PC dont vous voulez VOIR l'écran (la source) :
     onglet « Partager cet écran »  ->  Démarrer le partage
   Puis cliquez « Autoriser dans le pare-feu » (une seule fois, demande les droits admin).

2) Sur le PC qui AFFICHE la fenêtre (le viewer) :
     onglet « Connexions »  ->  Rechercher  ->  Afficher
   « Enregistrer » garde la connexion pour la prochaine fois.
   Si la recherche ne trouve rien, saisissez l'IP affichée sur la source
   (onglet « Partager cet écran », rubrique « Adresses de ce PC »).

Raccourcis : modifiables dans l'onglet « Raccourcis » de l'interface.

Réglages (opacité au survol, disposition PiP/PbP, fps, débit, écran capturé…) :
onglet « Réglages d'affichage » et « Partager cet écran ». Ils sont enregistrés
automatiquement dans %APPDATA%\pip-pbp\pip-pbp.toml.

Dans la fenêtre PiP (Alt = touche d'interaction, curseur sur la fenêtre) :
  - souris dessus         -> transparente, clics et touches passent derrière
  - Alt maintenu          -> fenêtre normale : la déplacer, la redimensionner
  - Alt + clic droit      -> menu de toutes les options (se ferme en lâchant Alt)
  - Alt+1 / Alt+2 / Alt+3 -> coin (PiP) / moitié gauche / moitié droite (PbP)
  - Alt+A                 -> étirement libre
  - Alt+haut / Alt+bas    -> opacité au survol
  - Alt+Q                 -> fermer la fenêtre
  - Ctrl+Alt+K            -> prendre / rendre la main sur l'autre PC (partout)

Contrôle à distance (souris et clavier de l'autre PC) :
  - sur la source : cocher « Autoriser l'autre PC à piloter… » et noter le code
  - sur le viewer : saisir ce code dans la connexion (Modifier)
  - dans la fenêtre PiP : Ctrl+Alt+K pour prendre / rendre la main

Fermer l'interface arrête aussi les fenêtres PiP et le partage lancés depuis elle.
